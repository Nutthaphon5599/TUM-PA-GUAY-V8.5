# Tum Pa Guay POS V8.5.4 – Mobile POS

พัฒนาต่อจาก V8.5.3 โดยคงระบบเดิมทั้งหมด และเพิ่มการใช้งาน POS บนมือถือให้สะดวกขึ้น

## เพิ่มใน V8.5.4
- ปุ่มบิลแบบลอยเต็มความกว้างบนมือถือ พร้อมจำนวนรายการและยอดรวม
- เพิ่มอาหารจากการแตะการ์ดเมนู
- เปิดบิลเต็มหน้าจอบนมือถือ
- เพิ่ม/ลดจำนวนด้วยปุ่มขนาดใหญ่
- ลบรายการอาหารจากบิล
- เพิ่มหมายเหตุแยกต่อรายการอาหาร
- บันทึกออเดอร์ / ออกบิลตรวจสอบ / รับเงินและปิดบิลได้จากมือถือ
- Payment modal ปรับสำหรับมือถือ
- รองรับ iPhone, Android และ PWA
- คง Pending Payment, VAT, Reports, Table Status และ Performance ของ V8.5.3
