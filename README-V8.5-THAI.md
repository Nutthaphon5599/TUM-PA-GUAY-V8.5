# Tum Pa Guay POS V8.5

## การปรับปรุงหลัก
- เปลี่ยนข้อความภาษาไทยในระบบ Admin, POS และ Reports เป็นภาษาลาว
- คงคำภาษาอังกฤษมาตรฐาน เช่น POS, Dashboard, Website, Export CSV และ Backup JSON
- เพิ่ม Top Menu แยกตามหมวด: ຕຳ, ຍຳ, ຕົ້ມ, ທອດ, ຕາມສັ່ງ, ປີ້ງ, ຜັດ, ເຄື່ອງດື່ມ
- เพิ่มอันดับ จำนวนที่ขาย ยอดขาย และเปอร์เซ็นต์ในแต่ละหมวด
- เพิ่มสรุปยอดขายตามหมวด และเปลี่ยนตามช่วงวันที่ที่เลือก
- คงระบบ Pending Payment ของ V8.4 ไว้ทั้งหมด

ไม่ต้องรัน SQL เพิ่ม เพราะใช้ตาราง categories และ menu_items เดิมของ Supabase
