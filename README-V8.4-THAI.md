# Tum Pa Guay POS V8.4

เวอร์ชันนี้เพิ่ม **Pending Payment** เพื่อแก้ปัญหาลูกค้าขอแก้รายการหลังพิมพ์บิลตรวจสอบ

## ขั้นตอนใหม่
1. เลือกอาหารและกด **ออกบิลตรวจสอบ**
2. นำบิลให้ลูกค้าตรวจสอบ โดยออเดอร์ยังไม่ถูกบันทึกเป็นยอดขายที่ชำระแล้ว
3. หากลูกค้าขอยกเลิกรายการ ให้กลับมาเปิดโต๊ะเดิมแล้วลบ/เพิ่ม/แก้จำนวน
4. กด **ออกบิลตรวจสอบใหม่** เพื่อพิมพ์บิลใหม่
5. เมื่อลูกค้าจ่ายเงินจริง กด **รับเงิน / ปิดบิล** แล้วจึงยืนยันการชำระ

ไม่ต้องรัน SQL เพิ่ม
