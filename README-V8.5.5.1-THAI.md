# Tum Pa Guay POS V8.5.5.1 Fix — Fast Lock Release

แก้ปัญหา Lock ค้างเมื่อมือถือ/คอมออกจากตู้บแล้วอีกเครื่องยังเข้าไม่ได้

สิ่งที่แก้:
- ออกจากหน้า POS ไปหน้า ตู้บ/ประวัติบิล -> ปลด Lock ทันที
- เปลี่ยนตู้บ -> ปลด Lock ตัวเดิมก่อน
- ปิด/ออกจากหน้าเว็บ -> ใช้ keepalive request เพื่อพยายามปลด Lock ให้สำเร็จ
- Heartbeat จาก 30 วินาทีเป็น 10 วินาที
- Safety timeout จาก 2 นาทีเหลือ 30 วินาที กรณีเครื่องดับ/เน็ตหลุด
- Realtime refresh สถานะ Lock หลังออกจากตู้บ

หลังอัปโหลด GitHub ให้ Run SQL เพิ่ม 1 ครั้ง:
`V8.5.5.1-FAST-LOCK-RELEASE.sql`

ทดสอบ: มือถือเปิดตู้บ 2 -> ออกจากตู้บ -> คอมควรเห็นกุญแจหายและเข้าได้ภายในประมาณ 1-2 วินาทีเมื่อเครือข่ายปกติ
