TUM PA GUAY POS V8.1 — SL-253 DIRECT PRINT

สิ่งที่เพิ่ม
- พิมพ์ตรงเข้าเครื่อง Thermal SL-253 ขนาด 80 mm ผ่าน QZ Tray
- จำชื่อเครื่องพิมพ์ในเครื่องแคชเชียร์
- ตัดกระดาษอัตโนมัติ
- เลือกเปิดลิ้นชักเก็บเงินหลังพิมพ์
- เลือกพิมพ์อัตโนมัติหลังชำระเงิน
- มี Browser Print เป็นระบบสำรอง

วิธีใช้งาน
1. อัปโหลดไฟล์ V8.1 ทับ Repository เดิมและ Push origin
2. ติดตั้ง QZ Tray บน Mac/Windows ของเครื่องแคชเชียร์
3. ติดตั้ง Driver ของ SL-253 และเพิ่มเครื่องพิมพ์ในระบบปฏิบัติการ
4. เปิด QZ Tray ทิ้งไว้
5. เข้า pos.html > ปุ่ม ตั้งค่าปริ้นเตอร์
6. กด เชื่อม QZ Tray > ค้นหาเครื่องพิมพ์ > เลือก SL-253 > บันทึก
7. ทดลองกด พิมพ์ตรง SL-253

หมายเหตุสำคัญ
- GitHub Pages เพียงอย่างเดียวไม่สามารถสั่ง USB โดยตรงได้ จึงต้องใช้ QZ Tray เป็น Print Bridge
- ครั้งแรก QZ Tray อาจถามอนุญาตเว็บไซต์ ให้กดยอมรับ
- V8.1 ไม่ต้องรัน SQL ใหม่ และไม่ลบประวัติการขายเดิม
- หาก QZ Tray ใช้งานไม่ได้ ให้กด Browser Print
