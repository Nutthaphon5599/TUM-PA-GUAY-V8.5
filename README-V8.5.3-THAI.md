# Tum Pa Guay POS V8.5.3 – Table Status & Performance

พัฒนาต่อจาก V8.5.2 โดยไม่เปลี่ยนฐานข้อมูล Supabase

## เพิ่มใหม่
- แสดงจำนวนตูบทั้งหมด
- แสดงจำนวนตูบที่กำลังใช้งาน (สถานะ open)
- แสดงจำนวนตูบที่กำลังคิดเงิน (สถานะ ready_to_pay)
- ใช้ Menu Cache แบบ cache-first เพื่อให้รายการอาหารขึ้นทันทีเมื่อเปิด POS
- ไม่โหลดประวัติบิล 100 รายการตอนเริ่ม POS; โหลดเมื่อเปิดหน้าประวัติเท่านั้น
- โหลดรูป 12 รายการแรกก่อน และ lazy-load รูปที่เหลือ
- Cache รูปจาก Supabase Storage ผ่าน Service Worker เพื่อให้เปิดครั้งถัดไปเร็วขึ้น
- ลดการ render ซ้ำขณะพิมพ์ค้นหาเมนู
